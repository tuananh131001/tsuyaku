C · Bilingual ledger

An interpreter's working sheet: Japanese and English side by side, one row per sentence, each row timestamped. Built for checking a translation against what was said, not just following along.

What changes

  • A three-column grid: time, Japanese, English. Rows line up, so your eye can jump across.
  • The gutter shows the time for settled rows and NOW / NEXT / HEARD for live rows, so the live band needs no extra label.
  • The header shows elapsed session time, backend and row count. A notice becomes an amber tag.
  • A corrected word is highlighted like a marker. "was" shows what Gemini heard.
  • With Hide Japanese on, the panel narrows to time and English.

SwiftUI

Grid / GridRow (macOS 13+) for aligned columns. Timestamps come from SubtitleLine, which the transcript already formats. Medium effort.

Trade-off

It needs a wider panel (about 740pt). It's denser and less glanceable: better for careful reading than for watching a speaker.
